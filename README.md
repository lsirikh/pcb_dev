# PCB Development Archive

KiCad 회로도와 PCB 설계 실습, 미세먼지 장치 보드 자료를 모은 저장소입니다. 소프트웨어 실행 프로젝트가 아니라 회로·보드 설계 파일을 보관합니다.

## 구성

- `2044-breadboard-power`: 전원 보드 설계 자료
- `2045-test`부터 `2050-eeprom`까지: 풋프린트, 오디오, 네트, 다층·다중 시트 등 실습 자료
- `microdust_pcb`: 미세먼지 장치 관련 보드
- `library`: 부품 라이브러리

## 열어보기

프로젝트별 `.pro`, `.sch`, `.kicad_pcb`를 지원하는 KiCad 환경에서 확인합니다. 오래된 형식과 백업 파일이 함께 있으므로 원본을 보존한 사본에서 변환하는 편이 좋습니다. 부품 라이브러리 경로도 확인해야 합니다.

파일 보관 자체가 제작 검증이나 양산 가능성을 뜻하지는 않습니다. 실습과 장치 설계 자료를 구분해 참고하세요.
